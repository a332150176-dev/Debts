# פנקס — ניהול חובות והלוואות

אפליקציית Android בעברית ובכיוון RTL, עם ממשק מותאם למסכים קטנים ועבודה מקומית ללא חשבון.

## מה כלול
- רישום חוב והלוואה עם שם, סוג ההתחשבנות, סכום, מטרה, הערות ותאריך פירעון.
- רישום החזרים חלקיים או מלאים, כולל תאריך והערה לכל החזר.
- חישוב יתרה אוטומטי והעברה אוטומטית של חוב ששולם במלואו להיסטוריית החובות.
- חיפוש וסינון לפי סוג, מועד ואיחור.
- ציר מועדי פירעון ותצוגת סיכומים.
- ייצוא ושחזור גיבוי JSON מתוך המסך.
- נתונים נשמרים מקומית ביישום. אין סנכרון לענן, ולכן יש לייצא גיבוי אם מעבירים למכשיר אחר.

## הורדת APK
לאחר שהריצה הראשונה של **Build Pinkas Android APK** תסתיים בהצלחה, קובץ ה-APK יופיע ב-[Releases](https://github.com/a332150176-dev/Debts/releases/latest) וגם כ-Artifact תחת לשונית Actions.

ה-APK הוא build להתקנה ידנית (debug). באנדרואיד ייתכן שתצטרך לאשר התקנה ממקור זה.

## בנייה מקומית
נדרשים Node.js 22+, Java 21 ו-Android SDK. הפקודות:
```sh
npm install
npm run build
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

## פרטיות
אין שרת ואין חשבון. הנתונים נשמרים באחסון המקומי של האפליקציה. מחיקה של נתוני האפליקציה או הסרתה עלולות למחוק רשומות שלא גובו.
